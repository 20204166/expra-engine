# Blacksite Relay

A complete Expra editor/runtime dogfood game.

## Controls
- WASD or Arrow Keys: move and aim
- Space or F: fire
- P: pause/resume
- R: restart

## Goal
Collect 4 access shards, rescue the relay engineer, then reach the north-east extraction gate before time expires. Security drones chase the operative and additional drones activate over time.

This version intentionally uses only renderer features that the current Expra
checkout supports end-to-end: rectangle, circle, text, sprite, colliders,
triggers, raycasts, scripts, hierarchy, input, scene lifecycle, and assets.
